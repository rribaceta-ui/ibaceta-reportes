El Cristorante S.A. — Pauta WEB + SALÓN sin canibalización

Asignación de Producto a Canal

12 WEB · 14 SALÓN
La regla: cada producto se pauta en UN solo canal, para que web y salón nunca peleen la misma venta. Asignación según: (1) lo que ya vende fuerte en web se mantiene en web (demanda probada, no se reemplaza); (2) enviables de margen alto se expanden en web con precio cerrado que absorbe logística; (3) voluminosos / pago presencial van a salón. Así corren las dos pautas en paralelo sin solaparse.
⚠️ La columna "enviable" es una estimación por tipo de producto — validar con el costo real de logística de cada uno. Y los WEB ⭐ voluminosos (Verticales, Freezer, Helvitrina) hoy convierten con pago/retiro físico: la pauta los mantiene en web pero la entrega sigue siendo presencial hasta resolver logística/pasarela.
